# app-factory-agents

Агентная среда ИИ разработки ПО программно-аппаратной среды пилотирования и прототипирования МАС БФМ с элементами сильного ИИ (AppFactory).

Репозиторий содержит исходный код, приведённый в документе «Текст программы» RU.СНАБ.01036-02 12 02.
Состав и структура каталогов совпадают с документом; прежнее наименование продукта
заменено на AppFactory, адреса испытательных стендов — условными значениями.

## Назначение

Компонент реализует конфигурируемых агентов, аукцион распределения задач, исполнение графа процесса, точки согласования с человеком, контекст проекта, реестр инструментов, подключение MCP-серверов и взаимодействие по протоколу A2A. Назначение и устройство компонента изложены в документе «Описание программы» RU.СНАБ.01036-02 13 02.

## Состав

Раздел содержит полный исходный текст компонента «Агентная среда ИИ разработки ПО». В состав входят программные модули каталогов src/agents, src/orchestration, src/context, src/tools, src/integrations и src/schemas.

## Происхождение

Код собран из репозитория продукта AppFactory (ветка разработки демонстрационных сценариев
и связанные с ней ветки служб) и предназначен для сопровождения отчётной документации.
Описание устройства и порядка запуска приведено в документах «Описание программы»
и руководствах комплекта.
